# 密码管理器 (Password Vault)

> 一个**完全本地化**、**UI 完全可自定义**的个人密码管理工具。
> 用 Python 写后端、用 Web 技术写前端，数据只存在你自己的电脑上。

---

## 一、为什么要做这个项目

事情的起因很简单：Edge 浏览器自带的"密码自动填充 / 密码记录器"太难用了。

- **太丑了。** 那么大的屏幕空间，明明可以做得好看一点、甚至像标签页一样一目了然，结果却是一行一行的表格，密密麻麻，极不直观。每次打开它，光是看着就难受。
- **太难找。** 想找一个特定网站的密码，虽然它能自动填充，可一旦要把密码告诉媳妇或闺女、需要手动翻找的时候，那一长串列表里翻来翻去，非常费劲。
- **不可控。** 界面长什么样、数据存在哪里，用户说了不算。

所以我干脆自己做一个：

1. **把 UI 的修改权交还给用户。** 界面用纯 HTML / CSS / JS 实现，你喜欢什么样就改成什么样——卡片、网格、标签页、暗色主题，随便折腾。把"好不好看"的决定权交给用户，这才是最优秀的做法。
2. **数据保存在本地才安全。** 所有密码都存在你自己电脑上的一个 SQLite 数据库文件里，不上传任何服务器。
3. **用 Python 写，是为了以后好扩展。** 后续想加云同步、写一个 HTTP API 对外提供接口、或者做移动端联动，Python 生态都现成、都方便。

---

## 二、核心特性

- 本地存储：数据保存在当前目录的 `webps.data`（SQLite），不联网、不上传。
- 自定义 UI：前端为独立的 `html/index.html`、`index.css`、`index.js`，改文件即可改界面。
- 分类管理：左侧分类列表，支持增 / 删 / 改（重命名）分类。
- 记录管理：按分类浏览、搜索密码记录（名称 / 网址 / 账号）。
- 自动截图：后台用系统浏览器（Edge / Chrome）为每个网站自动截取快照，缩略图直观展示，告别纯文字列表。
- CSV 互通：一键导入 Edge 等浏览器导出的密码 CSV，也可导出为兼容 Edge 导入的 CSV（额外保留 `classify` 分类字段）。
- 前后端通信：通过 pywebview 的 `js_api` 把 Python 方法直接暴露给前端 JavaScript 调用。

## 三、技术栈

| 层次 | 技术 | 说明 |
| --- | --- | --- |
| 桌面窗口 / 容器 | [pywebview](https://pywebview.flowrl.com/) | 用一个系统 WebView 窗口承载前端页面 |
| 前端界面 | HTML + CSS + JavaScript | 可完全自定义的 UI，渲染在 WebView 中 |
| 后端逻辑 | Python 3 | 通过 `js_api` 暴露 API 给前端 |
| 数据存储 | SQLite（`webps.data`） | 单文件数据库，本地、零配置 |
| 网页截图 | [Playwright](https://playwright.dev/python/) | 调用本机 Edge / Chrome 无头截图 |
| 数据交换 | CSV（`utf-8-sig`） | 兼容浏览器导入 / 导出 |

## 四、项目结构

```
.
├── 运行文件.py       # 程序入口：建库 -> 导入CSV -> 生成默认前端 -> 启动截图 -> 打开窗口
├── 建立数据库.py     # 创建 SQLite 数据库与 pws_vault 表、索引，提供插入数据函数
├── api接口.py        # API 类：暴露给前端 JS 的后端方法（分类 / 记录的增删改查等）
├── 创建文件夹.py     # 首次运行创建 html/ 目录并写入默认前端文件
├── 写入index.py      # 默认前端结构（HTML）
├── 写入css.py        # 默认前端样式（CSS）
├── 写入js.py         # 默认前端脚本（JS）
├── 读取csv文件.py    # 扫描当前目录 CSV，校验表头并智能导入，导入后删除源文件
├── 导出csv.py        # 将全部 / 指定分类记录导出为 CSV（兼容 Edge 导入）
├── 截图模块.py       # 调用系统浏览器为网站截图，含后台截图线程
├── webps.data        # [运行时生成] SQLite 数据库文件
└── html/             # [运行时生成] 前端目录，可自由修改
    ├── index.html
    ├── index.css
    ├── index.js
    └── images/       # 网站截图存放目录
```

## 五、安装与运行

### 1. 环境要求

- Python 3.10 及以上（源码标注面向 Python 3.15）
- 本机已安装 Microsoft Edge 或 Google Chrome（用于网页截图）

### 2. 安装依赖

```bash
pip install pywebview playwright
```

> 截图功能会直接调用系统已安装的 Edge / Chrome，通常无需额外下载 Playwright 浏览器内核。
> 若提示找不到浏览器，可执行 `playwright install chromium` 作为兜底。

克隆源码可按自己需求编辑

`git clone https://gitee.com/abc62201/mipage.git`

### 3. 启动

```bash
python 运行文件.py
```

首次运行会自动完成：建立数据库 -> 导入当前目录下的 CSV -> 生成 `html/` 前端文件 -> 启动后台截图 -> 弹出"密码管理器"窗口。

## 六、使用说明

- **添加分类**：点击左侧分类列表顶部的 `+` 按钮。
- **管理分类**：在分类项上**右键**，可重命名或删除分类。
- **添加记录**：点击右上方"添加"，填写分类、名称、网址、账号、密码、备注。
- **搜索**：在顶部搜索框按名称检索当前分类下的记录。
- **刷新截图**：点击"刷新截图"，为记录里的网站重新抓取快照。
- **导出 CSV**：点击"导出 CSV"，生成带时间戳的备份文件。

## 七、导入 / 导出 CSV

### 导入（把浏览器密码搬进来）

1. 在浏览器（如 Edge）中"导出密码"得到 CSV 文件。
2. 把该 CSV 放到本程序**当前目录**下。
3. 启动 `运行文件.py`，程序会自动扫描、校验表头并导入，导入完成后删除源 CSV。

CSV 必需表头：`name, url, username, password, note`；`classify`（分类）为可选字段，缺失时使用默认分类。

### 导出

导出表头为 `name, url, username, password, note, classify`，可直接被 Edge 等浏览器导入，同时保留分类信息，方便迁移与备份。

## 八、自定义 UI（核心卖点）

前端文件在首次运行后会落地到 `html/` 目录，**直接编辑这三个文件即可改变界面**：

| 文件 | 作用 |
| --- | --- |
| `html/index.html` | 页面结构与布局 |
| `html/index.css` | 配色、卡片、网格、主题等外观 |
| `html/index.js` | 交互逻辑，通过 `pywebview.api.<方法名>()` 调用后端 |

你可以把它们改成卡片瀑布流、标签页、暗色模式等任意样式，而后端数据与逻辑无需改动。

> 想新增功能时，在 `api接口.py` 的 `API` 类里加一个 Python 方法，前端用 `pywebview.api.方法名(...)` 即可调用。

## 九、数据与安全

- 所有数据仅存储于本地 `webps.data`（SQLite 单文件），程序运行时不向任何外部服务器发送密码。
- 表 `pws_vault` 主要字段：`classify`(分类) `name`(名称) `url`(网址) `username`(账号) `password`(密码) `note`(备注) `image`(截图路径)，并以 `UNIQUE(url, username)` 去重。
- 建议定期使用"导出 CSV"做离线备份，并妥善保管备份文件。

> 提示：当前版本密码为明文存储于本地库，请勿将 `webps.data` 与导出的 CSV 文件随意外发。加密存储可在后续版本扩展。
