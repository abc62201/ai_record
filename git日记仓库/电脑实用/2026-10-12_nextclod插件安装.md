首先在[All apps - App Store - Nextcloud](https://apps.nextcloud.com/)

官网下载插件找到的版本鼠标点击Show all releases查看版本下载
下载后放到custom_apps文件里前提是做好了映射

| 本地                              | docker                    |
| ------------------------------- | ------------------------- |
| F:\docker\nextcloud\data⁠       | /var/www/html/data        |
| F:\docker\nextcloud\themes      | /var/www/html/themes      |
| F:\docker\nextcloud\themes      | /var/www/html/themes      |
| F:\docker\nextcloud\logs        | /var/log                  |
| F:\docker\nextcloud\config      | /var/www/html/config      |
| F:\docker\nextcloud\custom_apps | /var/www/html/custom_apps |
然后给于权限
1. 先在docker启动Nextcloud 
2. 进 PowerShell 执行赋权（这步一定要做，不然可能还会白屏）：
      docker exec -it nextcloud bash  
   进容器后敲：
      chown -R www-data:www-data /var/www/html/custom_apps
   exit   
3. 重启容器：
      docker restart nextcloud
4. 在停止Nextcloud 容器然后把插件解压后复制到custom_apps
5. 去网页中开启插件
