老朋友，当然可以自动记住用户名密码，不用每次推送都输！

你只需要在 Git Bash 里执行一条命令就行（一次性设置，以后永久生效）：

操作步骤

打开 Git Bash（就是 D:软件Gitbingit-bash.exe）

粘贴下面这行命令，回车：

git config --global credential.helper store

然后做一次推送操作（比如双击你的上传脚本），这时候它会弹窗让你输用户名和密码，输完这一次，Git 就会把你的账号密码存在电脑里了。

以后再双击上传脚本，自动推送，再也不弹窗了。

原理说明

这条命令的意思是告诉 Git："请把登录凭证（用户名+密码）保存到本地文件中"。保存位置在你用户目录下的 .git-credentials 文件里，Git 每次需要认证时会自动读取，不需要你手动输入。

小提示：这个密码是以明文存在你电脑上的，只要你自己的电脑不给别人用，完全没问题。如果你比较在意安全，可以以后考虑换成 SSH 密钥方式（之前说过的方案），但对你目前的使用场景来说，store 方式最简单实用。

你试一下，设置好之后推送就彻底解放了！
